# Identity & Mail — `june8th.eu.org`

## Layout

```text
Internet
  ├─ nginx :80/:443 ── idp.june8th.eu.org   → Authelia (SSO/OIDC)
  │                 ├─ mail.june8th.eu.org  → Bulwark (webmail)
  │                 └─ mx.june8th.eu.org    → Stalwart (admin/JMAP)
  ├─ SMTP/IMAP ports ────────────────────── → Stalwart
  └─ vault.june8th.eu.org                   → Vaultwarden (Authelia OIDC SSO)

Docker network: Authelia + Stalwart ── OpenLDAP (users and mail accounts)
Persistent named volumes: LDAP, Authelia, Stalwart, Bulwark, Vaultwarden
```

| Public ports | Service |
|---|---|
| 80, 443 | nginx / HTTPS sites |
| 25, 465, 587 | SMTP / submission |
| 993, 995 | IMAPS / POP3S |

## Quickstart (fresh VPS)

1. Point DNS records below at the VPS. Install a TLS certificate covering `june8th.eu.org` and `*.june8th.eu.org`; nginx and Stalwart use `/etc/letsencrypt` by default.
2. Clone the repo, then run each bootstrap script **once**:

   ```bash
   ./scripts/00-generate-env.sh             # creates private .env + OIDC secret digests
   ./scripts/01-generate-authelia-keys.sh   # creates the per-host OIDC signing key
   ```

   Keep `.env`, `authelia/keys/` and `authelia/secrets/` private. `.env` is gitignored: `git clean -Xdf` can delete it without deleting Docker volumes. Restore the matching `.env` backup if it goes missing; a newly generated LDAP password cannot unlock an existing LDAP volume. The generator refuses to create/rotate `.env` while this Compose project's persistent volumes exist. Do not remove volumes unless their data is disposable.
3. Bootstrap Stalwart declaratively:

   ```bash
   bash scripts/02-bootstrap-stalwart.sh
   ```

   The script assumes Stalwart RocksDB at `/var/lib/stalwart`; it starts only the services needed for setup, sets the LDAP `svc-mail` password only if the account has no password yet, starts Stalwart briefly in recovery mode, dry-runs and applies `stalwart/bootstrap.ndjson`, then runs `docker compose down --remove-orphans`. **When the script exits, all project containers are stopped and removed; named volumes are preserved** (it never uses `down -v`). It configures the LDAP directory, domain, DKIM mode, and mounted TLS certificate without the WebUI wizard.

   Start the full stack only when you want it running:

   ```bash
   docker compose up -d
   docker compose ps
   ```

4. Vaultwarden is enabled with Authelia OIDC-only sign-in. SSO-only sign-in is restricted by Authelia and the `june8th.eu.org` email-domain whitelist. Visit `https://vault.june8th.eu.org`; Authelia is at `https://idp.june8th.eu.org`.

## DNS records

Replace `<VPS_IP>` with the server's public IPv4. Add AAAA records only if IPv6 is configured.

| Type | Name | Value |
|---|---|---|
| A | `idp` | `<VPS_IP>` |
| A | `mail` | `<VPS_IP>` |
| A | `mx` | `<VPS_IP>` |
| A | `vault` | `<VPS_IP>` |
| MX | `@` | `10 mx.june8th.eu.org.` |
| TXT | `@` | `v=spf1 mx -all` |
| TXT | `_dmarc` | `v=DMARC1; p=quarantine; rua=mailto:admin@june8th.eu.org` |
| TXT | `<selector>._domainkey` | DKIM public key generated by Stalwart |

Publish the selector and value shown by the current Stalwart instance, including its `v=DKIM1; k=...; p=...` fields. Set the VPS reverse DNS/PTR to `mx.june8th.eu.org` at the hosting provider.
